# UI 一致性审查

审查日期：2026-09-07。

现有界面以中性背景、青绿色强调色、圆角面板和紧凑操作区为基础，
主要页面已经复用 `Serlink*` 组件。本次保留这一方向，修正公共组件、
窄屏布局和状态展示中的具体问题。

## 已修正的问题

| 问题 | 修正 |
| --- | --- |
| Forui 主按钮白字与背景对比不足：浅色 3.74:1，深色 1.86:1 | 实心主按钮使用 `accentStrong`，分别达到 4.94:1、5.01:1。 |
| 深色危险按钮白字对比只有 3.35:1 | 新增 `statusDangerFill`，实心危险按钮达到 5.36:1；状态文字继续使用原有危险色。 |
| 主机、片段、传输列表分别使用 16px、12px、顶部 0px 的桌面留白 | 共用 12px 列表内边距；移动端保留已有边距。 |
| 主机和片段空状态与其他页面字号、间距不同，短窗口下不能滚动 | 共用 `SerlinkEmptyState`，统一图标、标题、说明和操作间距；正文过高时可滚动。 |
| 传输准备状态没有加载指示 | 使用公共加载指示器。 |
| 自绘点击组件只有鼠标反馈，没有键盘焦点和激活行为 | `SerlinkPressable` 支持 Tab、焦点边框、Enter/Space；选择标签和分段控件补充选中语义。 |
| 长主机标签及指纹变化状态挤压主机信息，在窄屏溢出 | 窄屏或大字号下分行显示名称、地址、状态和标签；宽屏标签也受可用宽度限制。 |
| 800×600 桌面窗口、1.5 倍字号下语言选择框向下溢出 3px | 设置操作槽高度随文字缩放。 |
| 证书、指纹、导出、粘贴及 Agent 授权弹窗的正文可能超过可用高度 | 正文可滚动，操作按钮留在底部；不可撤销确认使用公共危险按钮。 |

## iPhone 设计调整（根据截图反馈）

- 设置分组标题移到列表面板外，去掉重复的分组图标；行图标使用 28pt 槽位，标题与分隔线共用 56pt 内容起点。
- 桌面设置分组标题和设置行统一为 16pt 左边距、28pt 图标槽、10pt 图文间距，修正截图中两套图标和文字基准不一致的问题。
- iPhone 设置使用 17pt 行标题、CupertinoSwitch，以及语言选择 Action Sheet；按钮和开关触控区至少 44pt，大字号下操作改为单独一行。
- 主机 tags 改为单行次要文字，避免多个胶囊堆叠；长内容截断，完整标签保留在提示及编辑表单中，指纹变化状态继续独立展示。
- 主机、凭据、代码片段和 WebDAV 编辑在 iOS 上使用 Cupertino 全屏模态页面，顶部放置“取消／保存”，正文独立滚动并避让键盘；桌面继续使用弹窗。
- iOS 编辑输入使用 CupertinoTextField，认证方式使用 CupertinoSlidingSegmentedControl；保留输入、保存及取消的既有业务逻辑。
- 底部使用五项 CupertinoTabBar，49pt 内容高度另加底部安全区；保留标签和选中图标，不把创建操作放入 tabs。
- 头部及主机行的 iPhone 图标操作增加到 44pt。

这些调整采用 Flutter Cupertino 的 iOS 交互和视觉惯例；真机系统字体、键盘与辅助功能体验仍需设备验收。

## 后续保持一致的约定

- 页面颜色从 `context.tokens` 读取；白字实心按钮使用对应的深色填充令牌。
- 主列表使用公共列表内边距与 `ListRow`；页面空状态使用 `SerlinkEmptyState`。
- 弹窗、按钮、选择框和提示优先使用现有 `Serlink*` 组件。
- 自绘可点击内容复用 `SerlinkPressable`，保留键盘焦点与禁用行为。
- 标签、状态和操作区必须接受宽度约束；长内容需要换行、截断或滚动。
- 设置分组、嵌套表单和终端工具允许适合自身信息密度的布局，继续共用语义色、控件和圆角尺度。

- iOS 设置文字对齐、44pt 控件、语言 Action Sheet，以及带 34pt 底部安全区的 tab bar。
- 主机表单在 300pt 键盘遮挡下的正文可达性与顶部保存位置，以及片段、凭据编辑的取消返回行为。
- 桌面设置分组图标与行图标中心、标题与行文字起点的几何对齐。

首轮核对了 26 张测试渲染截图；iOS 调整后重新渲染主要页面及表单的深浅主题截图，

本次没有进行 macOS/iOS 真机手动验收，系统键盘、VoiceOver 和平台原生文件选择器

## iOS 26 原生 Liquid Glass tab bar

- iOS 26 及以上、使用 Xcode 26 及以上 SDK 构建时，通过 Flutter `UiKitView` 嵌入系统 `UITabBar`。保持 UIKit 默认 appearance，使用 SF Symbols；玻璃材质、选中动画及辅助功能由系统管理。
- 原生侧回传实际高度；Flutter 保留五个工作区的状态与切换逻辑，并同步本地化标题、主题和选中项。旧系统或桥接不可用时使用 Cupertino fallback。
- 平台视图位于 Flutter 路由树内，表单与弹窗保持现有覆盖关系。键盘出现时隐藏 iPhone 底栏，由外层 Scaffold 统一处理键盘高度。
- 这是独立的原生 `UITabBar`，没有接入 `UITabBarController` 的随滚动自动收缩功能。
- 开发验证环境：Xcode 27 beta / iOS 27 模拟器，最低部署版本仍为 iOS 15。已完成原生独立视图的系统玻璃外观验证、Swift 类型检查及完整 iOS Simulator App 构建。iOS 26 真机外观仍需设备验收。
- 本轮验证：44 项工作区 smoke tests、4 项桥接测试、3 项移动端测试通过（共 51 项），`flutter analyze --no-pub` 与 `git diff --check` 通过。桥接测试覆盖旧系统/缺失插件回退、选中项与语言同步、原生高度、非法回调及销毁；移动端测试覆盖键盘隐藏/恢复底栏。
- 完整 App 的模拟器点击/截图验收未完成：无签名启动在现有 CloudKit 初始化处因 entitlement 缺失终止；补齐本地签名后模拟器启动服务仍未可靠返回，XCTest runner 也出现启动失败。本轮未改动 CloudKit 逻辑，原生独立视图的外观验证不等同于完整 App 或 iOS 26 真机验收。
