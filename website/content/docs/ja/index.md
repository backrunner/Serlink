## ワークスペースを作成する

Serlink を開き、パスフレーズでボールトを作成します。復旧キーは、このデバイスとは別の安全な場所に保管してください。パスフレーズを忘れた場合に必要です。既存のボールトがある場合はロックを解除します。

Serlink アカウントは不要です。アクセス権のある SSH サーバーと、管理者から提供された認証情報が必要です。

## ホストを追加する

**ホスト**で名前、ホスト名または IP、ポート、ユーザー名、認証方式を入力します。同じパスワードや鍵を使うホストには認証情報を再利用できます。[ホスト設定](/docs/hosts)をご覧ください。

## ターミナルを開く

ホストの**ターミナル**操作を選びます。初回は信頼できる情報源でホスト鍵の指紋を照合してから承認してください。認証後、セッションがワークスペースに開きます。

Unix 系サーバーでは、次の簡単なコマンドから始められます。

```sh
pwd
```

同じホストの **SFTP** から[リモートファイルを閲覧](/docs/sftp)できます。暗号化、復旧、ロックについては[ボールトのガイド](/docs/vault)を参照してください。

## プラットフォームを確認する

macOS App Store 版と直接配布版ではローカル機能が異なります。公開リリースを準備中です。[公開状況](/download)をご確認ください。
