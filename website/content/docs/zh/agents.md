## 访问方式

macOS 上，Serlink 提供经过认证的本机回环 MCP 端点。外部代理通过它请求会话，由你在应用中批准。密码和私钥留在保险库，不交给代理。

Serlink 不内置 AI 模型。被授权的代理可能按自身提供商与配置处理终端内容，请了解该代理的数据处理方式。

## 配置客户端

打开**设置 → MCP / 代理访问**，把运行中的应用显示的 HTTP 配置复制到 MCP 客户端。地址与令牌属于该次应用运行，不要分享令牌。

```json
{
  "mcpServers": {
    "serlink": {
      "type": "http",
      "url": "http://127.0.0.1:<port>/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

两个 macOS 发行渠道均支持 HTTP 访问。独立 stdio 辅助程序仅在直接发行版中提供，请使用应用复制出的配置，不必猜测安装路径。

## 模型命令防护

在**设置 → MCP / 代理访问 → 管理 → 命令防护 → 配置**中，填写自己的 TypeSafe API key，明确同意共享完整命令后启用模型防护。默认模型为 `jev-1.13.0`，启用前不会发起模型请求。启用后，代理提交的命令会发送给 TypeSafe 判断风险；密钥与设置保存在本机安全存储中，不参与保险库同步和备份；密钥会发送至 TypeSafe 用于认证。完整命令可能包含密码、令牌或个人信息。TypeSafe 可能根据服务条款留存请求数据，不保证零留存，详见[隐私政策](/privacy)。旧配置在重新同意前不会发送请求。

本机硬拦截规则始终生效。模型认为危险、判断不明确、服务不可用或返回无效结果时，命令都不会执行，已有的本会话规则授权也不能跳过模型检查。请通过 `serlink_exec` 提交完整命令；开启防护后会拦截分段输入、历史控制和单独回车，仍可使用 Ctrl-C 中断。这些检查不是 Shell 沙箱，也不是绝对安全保证。

## 授权与撤销

打开主机会话前先解锁保险库。客户端首次请求某个主机时需要批准；高风险命令可能要求再次确认，部分破坏性模式会被阻止，但这些检查不是完整的安全保证。

授权只保存在内存中，退出应用后失效。可以在**设置 → 代理访问**撤销授权并关闭代理会话。执行结果是稳定后的屏幕文本，并非确认过的进程退出码；长时间运行的命令可能需要较长超时。


## 发现、已有连接与下载

发现主机及当前连接前，需要明确同意共享信息。严格主机隐私仅返回主机名称和 ID；普通发现还包含地址、用户名及连接设置。两种模式均不返回启动命令或已存储的凭据记录。发现授权不允许访问终端内容或文件。

接管已有连接需要单独授权该连接，范围包含已有终端缓冲区及后续输出。新建会话的主机授权不涵盖已有连接。访问通知会打开应用内的完整说明；短命令仍可通过通知批准单次执行。

Mac App Store 版的 MCP 下载保存在应用私有存储中。完成后可在传输列表选择**导出**，通过系统保存面板保存。直接分发版使用 Downloads 下的新文件夹。下载文件不受保险库加密保护。
