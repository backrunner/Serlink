Serlink Support

Open the support form

Get connected

Create a vault, save its recovery key, add a credential in Settings, and add a host using that credential. Confirm the hostname, port and username. Verify the server's SHA256 host-key fingerprint before trusting a first connection or accepting a changed key.

Connection and transfer problems

Check server reachability, VPN/firewall settings and SSH/SFTP permissions. For a missing start directory, choose an accessible absolute path. Use only files you can safely replace when testing transfers. You can pause or cancel active transfers and retry supported failures while the relevant session is available.

Vault and sync

Use your passphrase or saved recovery key to unlock the vault. The developer cannot recover unknown credentials. Biometric unlock depends on supported hardware. Optional iCloud sync needs an iCloud account; WebDAV needs your configured endpoint. Review sync conflicts before choosing local or remote data. Remote deletion and local reset are separate operations: back up important data first.

iPhone and iPad

Use the document picker to upload and the share sheet to open or save downloaded files. Editing a file in another app does not automatically upload it. Keep Serlink open during transfers; background completion is not guaranteed. Local shells, OS SSH-agent authentication and desktop splits are not iOS features. Locking the vault does not disconnect existing sessions or transfers; close those explicitly.

Report an issue

Include the app version/build from Settings, iOS/iPadOS version, the affected action, and steps to reproduce. Diagnostic logs can be exported from Settings. Review attachments and remove credentials, private keys, server addresses, personal paths and terminal output before sending them. Never send your vault passphrase or recovery key.

打开支持表单

开始连接

创建保险库并保存恢复密钥，在设置中添加凭据，再创建使用该凭据的主机。核对地址、端口和用户名。首次连接或主机密钥变化时，请先核验服务器的 SHA256 指纹。

连接与传输问题

检查服务器可达性、VPN／防火墙和 SSH/SFTP 权限。起始目录不可用时选择有权限访问的绝对路径。传输测试请使用可以覆盖的文件；可暂停、取消正在运行的传输，在相关会话仍可用时重试支持的失败任务。

保险库与同步

使用密码或保存的恢复密钥解锁，开发者无法恢复遗失的凭据。生物识别需要受支持的硬件。可选 iCloud 同步需要 iCloud 账号，WebDAV 需要自己的端点。处理冲突前请核对本地与远程内容。远程删除和本地重置互相独立，操作前先备份重要数据。

iPhone 与 iPad

通过文件选择器上传，用分享面板打开或保存下载文件。外部编辑不会自动上传。传输时请保持 Serlink 在前台，后台完成不保证。iOS 不提供本地 shell、系统 SSH agent 认证或桌面分屏。锁定保险库不会中断已有会话或传输，请明确关闭。

反馈问题

请提供设置中显示的应用版本与构建号、iOS/iPadOS 版本、操作和复现步骤。可从设置导出诊断日志；发送附件前请移除凭据、私钥、服务器地址、私人路径和终端输出。不要发送保险库密码或恢复密钥。

Serlink サポート

サポートフォームを開く

接続する

ボールトを作成して復旧キーを保存し、設定で認証情報を追加して、その認証情報を使うホストを作成します。アドレス、ポートとユーザー名を確認してください。初回接続や鍵の変更時はサーバーの SHA256 指紋を確認してください。

接続と転送の問題

サーバーへの到達、VPN・ファイアウォール、SSH/SFTP 権限を確認してください。開始ディレクトリが使えない場合はアクセス可能な絶対パスを選びます。転送テストには上書きしてもよいファイルを使用してください。一時停止とキャンセル、対応する失敗タスクの再試行が可能です。

ボールトと同期

パスフレーズまたは保存した復旧キーで解除します。開発者は失った認証情報を復元できません。生体認証は対応ハードウェアが必要です。任意の iCloud 同期には iCloud アカウント、WebDAV には自分のエンドポイントが必要です。競合は内容を確認して解決してください。リモート削除とローカルリセットは別の操作です。重要なデータを先にバックアップしてください。

iPhone と iPad

書類ピッカーでアップロードし、共有シートでダウンロードしたファイルを開くか保存します。外部での編集は自動アップロードされません。転送中は Serlink を開いてください。バックグラウンドでの完了は保証されません。iOS はローカルシェル、OS SSH-agent 認証、デスクトップ分割表示に対応しません。ボールトをロックしても既存セッションや転送は続くため、明示的に閉じてください。

問題を報告する

設定にあるアプリのバージョンとビルド、iOS/iPadOS のバージョン、操作と再現手順を記載してください。診断ログは設定から書き出せます。送信前に認証情報、秘密鍵、サーバーのアドレス、個人的なパスとターミナル出力を除いてください。ボールトのパスフレーズや復旧キーを送らないでください。
