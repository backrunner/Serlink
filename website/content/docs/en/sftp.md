## Browse and edit

Open **SFTP** from a host. Navigate directories, search the current listing and use the file actions to rename, move, create or delete remote items. The server account’s permissions still apply.

Supported text files can be previewed or edited within the app’s size limits. Review changes before saving them to the remote server.

## Transfer a file

Upload or download through the file actions and choose the local location when prompted. Open **Transfers** to inspect progress, pause or resume supported operations, retry a failure and review destination conflicts.

Pause/resume support varies with the operation and connection. Directory transfers are desktop workflows; iOS uses the system document gateway and has different local-file access.

## Refresh and protect files

Refresh after changes made outside Serlink. Downloaded files live at the location you selected, outside the encrypted vault. Protect them separately from your [workspace records](/docs/vault).

Serlink does not promise background transfers after the app is suspended or closed. Keep it open for transfer work and inspect the final status.
