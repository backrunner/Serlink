## 创建工作区

打开 Serlink，用密码短语创建保险库。把恢复密钥保存在独立于这台设备的安全位置，忘记密码时需要它。已有保险库时，直接解锁即可。

不需要 Serlink 账号，但需要你有权访问的 SSH 服务器及管理员提供的认证资料。

## 添加主机

在**主机**中填写名称、主机名或 IP、端口、用户名与认证方式。多个主机使用同一密码或密钥时，可以复用身份。详见[主机配置](/docs/hosts)。

## 打开终端

选择主机的**终端**操作。首次连接时，请从可信来源核对主机密钥指纹，再选择信任。认证完成后，会话会在工作区打开。

Unix 类服务器上，可以用这个简单命令开始：

```sh
pwd
```

同一主机的 **SFTP** 操作用于[浏览远程文件](/docs/sftp)。保险库加密、恢复和锁定请阅读[保险库指南](/docs/vault)。
