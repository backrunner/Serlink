## Browse and edit

Open **SFTP** from a host. Navigate directories, search the current listing and use the file actions to rename, move, create or delete remote items. The server account’s permissions still apply.

Supported text files can be previewed or edited within the app’s size limits. Review changes before saving them to the remote server.

On iOS, choose **Download and open** when an in-app preview is unavailable. Text previews also offer **Open in…**. After the download completes, the system file menu lets you choose a compatible app or save a copy. Unsaved edits require confirmation before they are discarded; changes made in another app are not uploaded automatically.

## Transfer a file

Upload or download through the file actions and choose the local location when prompted. Open **Transfers** to inspect progress, pause or resume supported operations, retry a failure and review destination conflicts.

Pause/resume support varies with the operation and connection. Directory transfers are desktop workflows; iOS uses the system document gateway and has different local-file access.

On desktop, right-click a transfer for its available actions: open or export a completed item, pause, resume, retry, cancel or delete. On iOS, swipe left to reveal the delete button, or tap a completed file to open the system file menu. When a local file exists, deleting a transfer lets you remove only its record or delete the local file too.

## Refresh and protect files

Refresh after changes made outside Serlink. Desktop downloads use the location you selected; iOS downloads are stored in Serlink’s Downloads folder. These files are outside the encrypted vault. Protect them separately from your [workspace records](/docs/vault).

Serlink does not promise background transfers after the app is suspended or closed. Keep it open for transfer work and inspect the final status.
