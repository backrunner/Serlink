# App Store search and product-page plan

Prepared 2026-10-11 for macOS and iOS, using current product behavior and Apple's [product-page guidance](https://developer.apple.com/app-store/product-page/).

Names lead with Serlink, SSH and SFTP. Subtitles describe server/file management and encryption. Each locale has its own keyword set; the hidden field covers complementary terms without repeating the name or subtitle. No competitor brands, unsupported VPN/FTP features, rankings or popularity claims are used. These are relevance-based choices; no measured search-volume data is available.

| Locale | Name | Subtitle |
| --- | --- | --- |
| en-US | Serlink: SSH & SFTP Terminal | Server files & encrypted vault |
| zh-Hans | Serlink: SSH终端与SFTP文件 | 远程服务器管理与安全文件传输 |
| ja | Serlink - SSH接続とSFTP転送 | サーバー管理・ファイル転送・暗号化 |

Names and subtitles are at most 30 characters; keyword fields fit both 100 characters and 100 UTF-8 bytes. The app-level name/subtitle is shared across platforms. Platform descriptions explain native capabilities independently. Promotional text supports conversion and is not treated as a search-ranking field.

Lead screenshots with SSH, SFTP and encrypted workspace benefits. Use real native app captures, localized example data and valid Apple sizes. Do not show production credentials or unsupported mobile features. All Mac and iOS screenshot sets have been captured on their native Flutter engines using isolated fictional data.

After release, compare App Store Search impressions, product-page views and downloads by territory and platform in App Analytics. Test one meaningful metadata or screenshot change at a time; preserve a dated baseline. Use Apple's product page optimization only after eligible release state is reached. No exposure or ranking improvement is guaranteed.
