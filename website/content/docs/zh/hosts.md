## 连接配置

在主机配置中保存主机名、SSH 端口和用户名。显示名称与标签帮助你找到目标机器。密码、私钥和 OpenSSH 证书可以保存为保险库中的可复用身份。

目标只能通过堡垒机访问时，选择跳板主机。确认每一跳的认证资料有效，且前一跳可以访问后一跳。

## 信任服务器

接受新的主机密钥前，核对服务器管理员提供的指纹。已知密钥发生变化时，应先确认原因，再替换保存的密钥。可信密钥在**设置 → 已知主机**中管理。

## 导入已有配置

macOS 直接发行版可以导入和协调 OpenSSH 配置。App Store 版不提供此功能，也不提供 SSH Agent 认证；仍支持配置密码与密钥身份。

编辑连接资料请回到**主机**；管理凭据请解锁保险库后打开**设置 → 凭据**。[锁定保险库](/docs/vault)会阻止新的凭据读取。
