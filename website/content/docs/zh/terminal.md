## 把会话集中起来

从主机打开终端，在会话标签之间切换，无需再开一个窗口。桌面端可以把标签页分成多个窗格，方便对照机器或保留长时间运行任务的视图。

用终端缓冲区搜索查找之前的输出。断线时可以原位重连；重连会创建新的远程 Shell，不会恢复已终止的服务器进程。

## 终端字体

Serlink 内置 **JetBrainsMono Nerd Font Mono**，各平台的新终端配置默认使用它，无需额外安装字体即可显示 Nerd Font 和 Powerline 图标。

在**设置 → 终端 → 字体**中选择内置字体或其他已安装的 Nerd Font，也可以在自定义字体栏输入已安装的字体族。已有字体选择会保留，缺失图标由内置字体补全。主机专属终端配置可使用与全局设置不同的字体。

## 复用命令

在**片段**中保存常用命令，选择目标会话后检查内容再发送。片段可以要求确认，粘贴多行内容也可能触发粘贴保护。

## 本地与远程工具

直接发行的桌面版支持本地终端标签页；App Store 版不提供本地 Shell。SSH 转发与桌面 ZMODEM 工作流取决于会话和服务器配置，常规文件操作可以使用 [SFTP](/docs/sftp)。

## 连接失败时

检查主机、端口、用户名、身份与网络路径。设备休眠或网络切换后可能需要重连，诊断步骤见[排查指南](/docs/troubleshooting)。
