## SSH 连接失败

检查 DNS/IP、端口是否可达、VPN 或跳板机路径、用户名和身份。主机密钥变化时，与服务器管理员核对。认证成功后 Shell 启动失败，与服务器无法访问是不同的问题。

## 文件传输失败

检查服务器账号权限、本地选择的文件夹、可用空间和目标冲突。其他工具修改目录后，请刷新列表。修复原因后再重试，并查看队列最终状态。

## 同步与保险库问题

确认同步位置、网络、TLS 信任和服务权限，解锁保险库后再同步。重置前先备份，并分开保存恢复资料。关闭同步不会删除远程副本。

## 提供有效的问题报告

在**设置 → 诊断日志**导出脱敏日志。附上应用版本、系统版本、失败操作和大致时间，发送前检查文件。导出不会自动包含终端输出与命令内容。

联系[支持](/support)，不要附上密码、私钥、恢复密钥或 MCP 令牌。
