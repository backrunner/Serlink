## セッションをまとめる

ホストからターミナルを開き、ウィンドウを増やさずにタブを切り替えられます。デスクトップではタブを分割し、マシンの比較や長時間の作業を表示できます。

バッファ検索で以前の出力を探せます。切断したセッションはその場で再接続できますが、新しいリモート Shell が作られます。終了済みのサーバープロセスが復元されるわけではありません。

## ターミナルのフォント

Serlink は **JetBrainsMono Nerd Font Mono** を内蔵し、すべてのプラットフォームで新しいターミナル設定の既定フォントとして使用します。追加のインストールなしで Nerd Font と Powerline のアイコンを表示できます。

**設定 → ターミナル → フォント**で内蔵フォントやインストール済みの Nerd Font を選択できます。カスタムフォント欄にフォントファミリー名を入力することもできます。既存の選択は保持され、不足するアイコンは内蔵フォントで補完します。ホスト別のターミナル設定では、グローバル設定とは異なるフォントを使用できます。

## コマンドを再利用する

**スニペット**に常用コマンドを保存します。対象のセッションを選び、内容を確認して送信してください。確認を要求する設定ができ、複数行の貼り付けにも保護があります。

## ローカルとリモートのツール

直接配布のデスクトップ版はローカルターミナルに対応します。App Store 版ではローカル Shell を利用できません。SSH 転送やデスクトップの ZMODEM は接続先の設定にも依存します。通常のファイル操作には [SFTP](/docs/sftp)を利用できます。

## 接続に失敗した場合

ホスト、ポート、ユーザー名、認証情報、ネットワーク経路を確認します。スリープやネットワーク変更後は再接続が必要になる場合があります。[トラブルシューティング](/docs/troubleshooting)を参照してください。
