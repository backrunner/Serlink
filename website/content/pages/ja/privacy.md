Serlink は SSH ターミナルと SFTP のワークスペースです。Serlink アカウントは不要です。本ポリシーは現在のアプリのデータ処理を説明します。




## ローカルのワークスペース


ホスト、認証情報、スニペットとワークスペースのレコードはローカルの暗号化ボールトに保存します。デバイスの秘密情報は OS の安全なストレージを使用します。任意の生体認証解除はランダムなデバイスキーを保護し、ボールトのパスフレーズを保存しません。生体認証のテンプレートを Serlink が受け取ることはありません。


ターミナルデータはセッションの表示に使用します。ダウンロードしたファイルと平文で書き出した情報は選択した場所に保存され、ボールトの暗号化の対象ではありません。別途保護してください。ボールトのロックは新しい認証情報へのアクセスを防ぎますが、接続済みの SSH/SFTP セッションや転送を終了しません。




## サーバーと任意の同期


認証情報、コマンドとファイルは選択した SSH/SFTP サーバーに送信されます。サーバーの運営者は独自のポリシーに基づき処理できます。Serlink が運営する中継サービスは使用しません。


iCloud 同期は Apple の CloudKit プライベートデータベース、WebDAV 同期は設定したエンドポイントを使用します。暗号化されたスナップショットと必要なオブジェクトのメタデータを送信し、同期サービスはボールトの鍵を送信しません。Apple や WebDAV 運営者はサービスと接続のメタデータを独自のポリシーで処理する場合があります。同期を無効にしても既存のリモートコピーは削除されません。




## 診断と外部エージェント


広告・分析 SDK は含まず、診断ログを開発者へ自動送信しません。診断の書き出しはローカルで行い、接続の機密情報を伏せ、ターミナル出力を含めません。サポートへ送る前に内容を確認し、個人情報を取り除いてください。


任意の MCP エンドポイントは明示的に許可したセッションを外部エージェントに提供します。モデルによるコマンド保護は初期状態で無効です。自身の TypeSafe API キーを設定して有効にすると、エージェントが送信したコマンドを TypeSafe に送ってリスクを判定します。リクエストにホスト記録、SSH 認証情報、端末画面、コマンド出力は含めません。API キーと保護設定はデバイスの安全なストレージにのみ保存し、保管庫の同期やバックアップには含めません。TypeSafe は自身のサービスとプライバシーポリシーに基づいて処理します。許可したエージェントが自身の設定と提供者のポリシーに従って別途データを送信する場合があります。




## 管理、保存と削除


ホスト、認証情報、スニペット、バックアップ、書き出し、同期先とエージェントの許可は利用者が管理します。ローカルレコードは削除・リセットまで残ります。リモートデータ、バックアップと書き出したファイルは別途削除してください。復旧キーを安全に保管してください。復旧キーなしで失ったパスフレーズを開発者が復元することはできません。




## 連絡と更新


プライバシーに関する質問は[サポートページ](/support)の連絡先をご利用ください。データ処理が変わる場合は本ポリシーを更新します。



## ウェブサイトとサポート

**serlink.alkinum.com** は静的ページと製品画像を提供します。検索はブラウザ内で実行します。分析、広告ピクセル、アカウント、外部フォント要求はありません。ホストはページやファイルの要求を受け取り、サービス提供と保護のためネットワークメタデータを処理する場合があります。外観の設定はブラウザのローカルストレージに保存し、サイトデータの削除で消せます。

サポートフォームでは、入力したメールアドレス、種類、件名、本文、言語、任意のアプリや端末情報をCloudflare上のOnFireサポートシステムへ送信し、権限を持つ担当者が対応します。ファイルの添付機能はなく、診断、端末出力、ボールトの情報には自動アクセスしません。不正利用防止のためCloudflare Turnstileがブラウザー、端末、ネットワーク信号を処理し、送信回数の制限にはIPアドレスを使用します。認証情報や復旧情報を含めないでください。サポート記録の閲覧や削除はフォームから依頼でき、確認が必要な場合があります。記録は対応や法的義務に必要な期間保存します。

GitHub は独自のポリシーを持つ外部サービスです。Issue は公開されるため、非公開のセキュリティやプライバシー報告はサポートフォームをご利用ください。
