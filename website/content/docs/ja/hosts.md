## 接続プロファイル

ホスト名、SSH ポート、ユーザー名を保存します。表示名とタグで目的のマシンを探せます。パスワード、秘密鍵、OpenSSH 証明書は、ボールト内で再利用できる認証情報として保存できます。

踏み台経由でのみ到達できる場合はジャンプホストを選択します。各段階の認証情報と、前のホストから次への到達性を確認してください。

## サーバーを信頼する

新しいホスト鍵を承認する前に、管理者が提供した指紋と照合します。既知の鍵が変わった場合は理由を確認してから更新してください。**設定 → 既知のホスト**で管理できます。

## 既存の設定をインポートする

macOS 直接配布版は OpenSSH 設定のインポートと調整に対応します。App Store 版ではこの機能と SSH Agent 認証を利用できません。設定したパスワードと鍵の認証情報は利用できます。

接続の編集は**ホスト**、認証情報の管理はボールト解除後の**設定 → 認証情報**から行います。[ボールトのロック](/docs/vault)は新しい認証情報の読み出しを防ぎます。
