Serlink 是 SSH 终端与 SFTP 工作区，无需 Serlink 账号。本政策说明当前应用的数据处理方式。




## 本地工作区


主机、凭据、片段及工作区记录保存在本地加密保险库。设备密钥使用系统安全存储。可选的生物识别解锁保护一个随机设备密钥，不保存保险库密码；Serlink 不接收生物识别模板。


终端数据用于显示远程会话。下载文件和导出的明文资料保存在你选择的位置，不受保险库加密保护，请自行保护这些文件。锁定保险库会阻止新的凭据访问，但不会中断已建立的 SSH/SFTP 会话或传输。




## 服务器与可选同步


连接时，认证资料、命令和文件发送到你选择的 SSH/SFTP 服务器，服务器运营方可按其政策处理数据。连接不经过 Serlink 运营的中转服务。


iCloud 同步使用 Apple CloudKit 私有数据库；WebDAV 使用你配置的端点。同步上传加密保险库快照与必要的对象元数据，同步服务不上传保险库密钥。Apple 或 WebDAV 运营方可能按其政策处理服务及连接元数据。关闭同步会停止后续同步，不会自动删除已有远程副本。




## 诊断与外部代理


Serlink 无广告或分析 SDK，不会自动向开发者上传诊断日志。诊断导出保存在本地，排除终端输出并脱敏敏感连接信息。向支持人员发送前，请检查导出文件并移除私人内容。


macOS 的 MCP 端点仅在你同意发现授权后共享主机与连接信息。根据严格主机隐私设置，共享范围为名称、ID 和状态，或还包括地址、用户名、标签、路径及连接设置；不包含启动命令或已存储的凭据记录。终端和 SFTP 控制需要另行授权。读取或控制已有连接需要针对该连接单独同意，授权范围包含已有终端缓冲区。你可以在“设置 > 代理访问”中撤销权限；退出 Serlink 后权限失效。获授权的代理可能按其设置和政策，将共享的元数据、终端输出或远程文件信息发送给 AI 服务商。

模型命令保护默认关闭。启用前，你必须明确同意将代理提交的完整命令发送至 TypeSafe（api.typesafe.ai）进行风险评估。命令可能包含密码、令牌、地址或个人信息，这些文本不会自动脱敏。请求不会另行附加主机记录、已存储的 SSH 凭据、终端画面或命令输出。API Key 保存在本机安全存储中，并发送给 TypeSafe 用于请求认证。API Key、同意记录及保护设置不参与保险库同步或备份。你可以在保护设置中关闭功能或撤回同意；移除 API Key 也会清除同意记录。

TypeSafe 可能处理并留存命令内容、账号标识及请求使用信息，用于提供服务、安全防护、用量计费和服务遥测。请求会关联你的 TypeSafe 账号。零留存不受保证，具体取决于账号适用协议。TypeSafe 声明不会使用客户请求或响应训练 Jev。其处理和删除条款请参阅 TypeSafe 隐私政策与数据留存说明。Serlink 开发者不会收到这些命令或你的 API Key。

[TypeSafe 隐私政策](https://typesafe.ai/legal/privacy-policy) · [数据留存说明](https://help.typesafe.ai/articles/5974925716-how-is-submitted-data-used-or-retained)

Mac App Store 版的 MCP 下载先保存在应用私有存储中；你可以在传输列表中选择“导出”，通过系统保存面板保存已完成的文件。直接分发版的 MCP 下载保存在 Downloads 下的新文件夹中。下载文件不受保险库加密保护；仅删除传输记录不会删除对应的下载文件。




## 控制、保留和删除


你可以管理主机、凭据、片段、备份、导出文件、同步服务和代理授权。本地记录保留至删除或重置。远程数据、备份和导出文件各自保留，需要通过应用的远程数据控制或服务商删除远程副本，并单独删除备份及导出。请妥善保管恢复密钥；开发者无法在没有恢复密钥的情况下找回遗失的保险库密码。




## 联系与更新


隐私问题请使用[支持页面](/support)公布的联系方式。应用的数据处理方式变化时，本政策会更新。



## 本网站与支持

**serlink.alkinum.com** 提供静态页面与产品图片，文档搜索在浏览器内进行。网站不包含分析、广告像素、账号系统或远程字体请求。托管方仍会收到页面和资源请求，可能处理提供与保护服务所需的网络元数据。外观偏好保存于浏览器本地存储，清除网站数据即可移除。

支持表单将你填写的邮箱、分类、主题、正文、语言及可选应用和设备信息发送至托管于 Cloudflare 的 OnFire 支持系统，由授权人员处理请求。表单不提供文件上传，不会自动访问诊断、终端输出或保险库数据。Cloudflare Turnstile 会处理浏览器、设备和网络信号以防范滥用，我们也会使用 IP 地址限制提交频率。请勿发送凭据或恢复资料。你可通过支持表单请求访问或删除支持记录，我们可能需要验证请求。记录在处理请求及履行法律义务所需期间保留。

GitHub 链接会前往受其自身政策约束的外部服务。GitHub Issue 公开可见，私人安全与隐私问题请使用支持表单。
