## アクセスの仕組み

macOS の Serlink は認証付きのループバック MCP エンドポイントを提供します。外部エージェントのセッション要求をアプリ内で承認します。パスワードや秘密鍵はボールトに残り、エージェントに渡しません。

AI モデルは内蔵しません。承認したエージェントは自身の提供者や設定に従ってターミナルの内容を処理する場合があります。

## クライアントを接続する

**設定 → MCP / エージェントアクセス**を開き、動作中のアプリが表示する HTTP 設定を MCP クライアントにコピーします。アドレスとトークンはその実行に紐づきます。トークンを共有しないでください。

```json
{
  "mcpServers": {
    "serlink": {
      "type": "http",
      "url": "http://127.0.0.1:<port>/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

macOS の両配布版で HTTP 接続を利用できます。独立した stdio ヘルパーは直接配布版のみです。インストール先を推測せず、アプリから設定をコピーしてください。

## モデルによるコマンド保護

**設定 → MCP / エージェントアクセス → 管理 → コマンド保護 → 設定**で、自身の TypeSafe API キーを入力し、完全なコマンドの共有に明示的に同意してモデル保護を有効にします。既定のモデルは `jev-1.13.0` です。有効にするまでモデルへのリクエストは行いません。有効時はエージェントが送信したコマンドを TypeSafe に送り、リスクを判定します。キーと設定はデバイスの安全なストレージに保存し、ボールトの同期やバックアップには含めません。キーは認証のため TypeSafe に送信します。完全なコマンドには秘密情報や個人情報が含まれる場合があります。TypeSafe は規約に従ってデータを保持する場合があり、ゼロ保持は保証されません。[プライバシーポリシー](/privacy)をご覧ください。既存の設定でも同意の更新前は送信しません。

ローカルの禁止ルールは常に適用します。危険、不確実、サービス利用不可、無効な応答の場合は実行をブロックし、セッション単位のルール承認でもモデル確認を省略できません。`serlink_exec` で完全なコマンドを送信してください。有効時は分割入力、履歴操作、Enter のみの入力をブロックします。Ctrl-C での中断は引き続き利用できます。シェルのサンドボックスや完全な安全保証ではありません。

## 許可と取り消し

ホストのセッションを開く前にボールトを解除します。クライアントからそのホストへの初回要求は承認が必要です。危険性のあるコマンドは追加確認が必要になり、一部の破壊的パターンは禁止されますが、完全な安全保証ではありません。

許可はメモリ内のみで、アプリ終了時に失効します。**設定 → エージェントアクセス**で許可を取り消し、セッションを閉じられます。実行結果は落ち着いた画面のテキストであり、確認済みの終了コードではありません。長時間の処理には長いタイムアウトが必要な場合があります。


## 検出、既存の接続とダウンロード

ホストと現在の接続の検出には、情報共有への明示的な同意が必要です。厳格なホストプライバシーではホスト名と ID のみ、通常の検出ではアドレス、ユーザー名、接続設定も返します。起動コマンドと保存済み認証情報はどちらでも除外します。検出の許可では端末内容やファイルにアクセスできません。

既存の接続の操作には、その接続への個別の同意が必要で、既存の端末バッファと今後の出力も対象です。新しいセッションのホスト許可では既存の接続は操作できません。アクセス通知はアプリ内の完全な説明を開きます。短いコマンドの確認は引き続き通知から一回のみ許可できます。

Mac App Store 版の MCP ダウンロードはアプリの専用ストレージに保存します。完了後、転送一覧の**書き出す**からシステムの保存パネルで保存できます。直接配布版では Downloads 内の新しいフォルダに保存します。ファイルは保管庫では暗号化されません。
