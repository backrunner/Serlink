## Confirmed fixes

| Finding | Impact and fix | Verification |
| --- | --- | --- |
| Async conflict resolution returned a Future from inside try without awaiting | Manifest races bypassed the retry catch. Await resolution and the related-record timestamp fallback within their error boundaries. | Both keep-local and keep-remote race regressions pass. |
| Synchronous transfer startup exception | A transfer could remain running and consume its queue slot. Convert stream-creation/listen failures to a failed task after the current queue iteration. | Healthy queued work proceeds; retry remains possible. |
| SFTP refresh/invalidation race | An older listing could repopulate an invalidated cache. Track request identity and reject stale cache writes, including after session change/disposal. | Single/all invalidation and newer-refresh regressions pass. |
| Untrusted SFTP READDIR names | Recursive paths could escape their parent. Reject empty, dot, parent, slash/NUL and Windows separator/drive syntax. | Invalid-name regressions and real SFTP operations pass. |
| Face ID label on macOS | The UI implied a sensor unavailable on Macs. Use biometric-unlock wording in English, Chinese and Japanese. | Widget/golden checks and native macOS settings inspection. |
| Missing macOS privacy manifest | macOS lacked the existing iOS required-reason API declarations. Bundle an equivalent no-tracking manifest and check it in the release gate. | Manifest lint, built bundle inspection and gate checks. |

No remote/vault schema version changed; these changes are compatible. No local
Drift migration was needed.

  overwrite, chmod/time, batching and failure-mapping test passed against that
  fixture. It does not establish compatibility with every server implementation.
- Native installer helper: 10 Swift tests passed.

  2.241/5.550/9.449 ms for 1k/5k/10k lines; one notification per refresh and zero

  caused zero host-list reloads. Sync wrote zero unchanged records and one changed
  record; indexed queries were used. These are synthetic probes, not release frame
  timing or large-vault end-to-end benchmarks.

  passed; the 70.5 MB app is development signed and code-signature verification
