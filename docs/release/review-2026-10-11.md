# Serlink Apple release review — 2026-10-11

## Source review and fix

The checkout started clean on `main` at `f6bf868`. Review found a native iOS
compile failure: the CloudKit bridge used macOS public SecTask entitlement APIs
that are absent from the iPhoneOS SDK. The iOS bridge now gates unsigned
simulator execution at compile time; device signing and CloudKit account/service
responses govern physical-device availability. macOS retains its entitlement
inspection. No remote vault/sync schema version changed.

Version 1.0.0 uses iOS build 12 and macOS build 16, independently of the Dart
package build suffix. Native fix and build numbers were committed and pushed as
`834161a`.
